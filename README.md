decibel

lightweight open source music player for windows and android without ads or bloat

features
- song search and genre picker on startup
- custom playlists saved locally
- shuffle mode without repeating the last track
- automatic song lyrics
- offline mode on pc
- lightweight android app with background playback and lock screen controls

download
ready to install files are in the releases section on the right
- windows: decibel-windows-setup.exe
- android: decibel-android.apk

tech stack
- pc: python, pywebview, yt-dlp, html, css, js
- android: capacitor, html, css, js
